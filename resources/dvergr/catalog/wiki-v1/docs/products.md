# Products

- **Quill-3** (1991): a broadband seismometer, the company's first commercial product.
  Designed by Tomas Oduya, it was sold to observatories and universities.
- **Lantern** (1998): a rugged data logger for remote stations. It records to local
  storage and uploads over radio when a link is available.
- **Meridian** (2012): a monitoring network that combines Quill sensors and Lantern
  loggers with a central service. By 2020 the Meridian network had 340 stations.
